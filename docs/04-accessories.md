# A. 角色必备配饰（识别锚点）

## A0. 优先级

| 级别 | 配饰 | 缺了会怎样 |
|---|---|---|
| **P0 绝对必备** | **白色 X 发夹** | 头部特写里没有它 → 不是 Lyco |
| **P0 绝对必备** | **红内层发**（发下深红） | 变成普通黑发少女 |
| **P0 绝对必备** | **细长机械长杆** | 失去「纤细身体 × 巨大兵器」的反差 |
| **P1 强烈建议** | 腰带 **O 形环** | 失去「军装」的秩序感细节 |
| **P1 强烈建议** | **红滚边**（领口/袖口） | 服装变成纯黑块 |
| **P2 视画面** | 银色小扣、靴红扣带、红鞋底 | 降低完成度但不致命 |

**判定**：一张图只要**同时有 X 发夹 + 红内层发 + 长杆**，就能被认出是 Lyco。

---

## A1. 白色 X 形发夹 ★ P0

| 项目 | 规格 |
|---|---|
| 形状 | **X（交叉）**，两笔等长，**不是蝴蝶结、不是星星、不是一字夹** |
| 颜色 | `#F6F4F2`（眼白同色） |
| 尺寸 | 约 **0.35 个头宽**（别做大，就是个点缀） |
| 位置 | **右侧刘海**（角色自身的右侧 = 观众视角左侧） |
| 高度 | 刘海中部偏上，**不贴发际线** |
| 朝向 | 略微倾斜（约 15°），不要正十字 |
| 材质感 | 哑光白，**不画反光/宝石/金属边** |

**禁止**：做成发箍、做成两个、做成彩色、加装饰边。

#### ★ 低分辨率降级规则（必须遵守）

| 可用像素 | 呈现方式 |
|---|---|
| **≥ 16px** | 完整 X（两笔等长交叉） |
| **8–15px** | 白色十字点（圆点 + 十字） |
| **3–7px** | 黑发上**一个白色斜向短划**（约 45°） |
| **< 3px** | 放弃发夹，改用 **红内层发**做识别 |

> 来源：Minecraft 皮肤实测（8×8 的脸）证明 X 在 3px 下完全认不出。
> **降级必须提前规定，不能让每个画师自己猜。** 详见 [识别锚点 L3](07-recognition-anchors.md#l3--细节锚点白色-x-发夹)。

**为什么是它**：这是 Lyco 唯一的「记忆点」——大面积黑发上唯一的白。
它必须在**任何头部可见的画面里出现**，包括 Q 版、像素、Live2D 模型。
（但注意：**它不是充分条件** —— X 发夹是常见二次元符号，单靠它不足以证明是 Lyco。）

---

## A2. 红内层发 ★ P0

| 项目 | 规格 |
|---|---|
| 层级 | **藏在黑发下面**，不是挑染在表面 |
| 露出条件 | 发尾、头发翻动时、背面视角 |
| 颜色 | 暗部 `#8E1B24`，亮部 `#C02832` |
| 面积 | 头发总面积的 **20–35%**（静止时偏少，动态时偏多） |
| 渐变 | 从发根黑 → 发梢红，**自然过渡**，不是一刀切 |

**禁止**：红色做成表面挑染、做成大面积红发、做成对称条纹。

**判定**：静止时几乎看不见红，动起来才露 —— **这才对**。

---

## A3. 机械长杆 ★ P0

| 形态 | 长度 | 使用场景 |
|---|---|---|
| **收束** | ≈ 前臂长（0.5 身高） | 待机、日常、赶路 |
| **步枪** | ≈ 1.2 倍身高 | 中距离 |
| **镰刀** | 刃展 ≈ 1.5 倍身高 | 必杀、登场 |

| 部件 | 规格 |
|---|---|
| 杆身 | 细长，`#121218` 哑光黑 |
| 关节 | 银色 `#C8CCD0`，**小面积** |
| 核心 | 顶端**圆形红色核心** `#B62833`（唯一常亮元素） |
| 表面 | 哑光，**不画成镜面反光** |

**关键**：**兵器一定要大**。「纤细 × 巨大」的反差是这个角色的核心卖点。
把她和兵器画成同宽 = 丢掉设计。

---

## A4. 腰带 O 形环 · P1

| 项目 | 规格 |
|---|---|
| 形状 | 正圆环（**O**，不是 D、不是方扣） |
| 颜色 | 银 `#C8CCD0` |
| 位置 | 腰带扣**正下方**，垂下 |
| 尺寸 | 约 0.2 个头宽 |
| 数量 | **1 个**（多了变重装） |

---

## A5. 红滚边 · P1

| 位置 | 宽度 |
|---|---|
| 高领上缘 | 1px |
| 翻领边缘 | 1–2px |
| 前襟中线 | 1px |
| 袖口 | 2px |
| 下摆 | 2px |

**总原则**：**克制**。红滚边的总视觉面积不超过服装的 8%。

---

## A6. 配饰禁止清单

| ❌ 禁止 | 原因 |
|---|---|
| 勋章 / 奖章 / 肩章 / 臂章 / 绶带 | 会变成"军礼服"，偏离「实战军官」 |
| 项圈 / 锁链 / 铆钉 | 变成朋克，气质冲突 |
| 大面积蕾丝 / 蝴蝶结 | 用力过猛 |
| 发光魔法阵 / 符文 | 她是技术者不是法师 |
| 披风 / 斗篷 | 破坏「上半身静止」的轮廓 |
| 帽子 | 遮住头发 → 红内层发看不见 |
| 眼镜 | 会削弱半垂眼的表达 |
| 兽耳 / 尾巴 | 完全跑偏 |

# B. 衍生挂件生产规格

## B0. 通用生产铁律

任何衍生挂件都必须满足：

| 编号 | 要求 |
|---|---|
| **G1** | 必须包含 **X 发夹**（哪怕只有 3px，形状要能认出来） |
| **G2** | 必须包含 **红内层发** 或 **红色内衬**（黑+红是识别色） |
| **G3** | 只用 [配色指南](02-palette.md) 的色值 |
| **G4** | 无文字（除非是表情包的必要文案） |
| **G5** | 无徽章、无边框、无网格 |
| **G6** | 表情默认使用 **「默认」档**（半垂眼放松嘴） |
| **G7** | 输出**透明底 PNG**，除非该平台要求白底 |

---

## B1. 直播挂件

### B1.1 待机动画（最重要）

| 项目 | 规格 |
|---|---|
| 尺寸 | **800×1200**（竖版，半身到腰） |
| 时长 | **6–10 秒无缝循环** |
| 帧率 | 24 或 30 fps |
| 格式 | 带透明通道：WebM(VP9+alpha) / MOV(ProRes 4444) / PNG 序列 |
| 动作 | **上半身几乎不动**；只有呼吸（幅度 ≤ 2px）+ 头发/裙摆缓动 |
| 红 | 静止状态下**几乎没有红** |

**这条最关键**：她的待机就该是「一张会呼吸的照片」。
不要给她加扭头、眨眼以外的任何小动作 —— **安静本身就是卖点**。

### B1.2 进场特效

- 尺寸 1920×1080，透明底，2–4 秒
- 内容：**红色残影从画面外掠入 → 渐显成型**
- 红色面积可达 40%（这是唯一允许大面积红的地方）
- 收尾必须**安静下来**（残影散去，只剩静止的她）

### B1.3 直播间装饰

| 部件 | 尺寸 | 要点 |
|---|---|---|
| 场景底图 | 1920×1080 | 冷灰/深色，**不要花哨背景** |
| 边框 | 1920×1080 | 细线，`#262630`，**不要金边** |
| 粉丝牌 | 200×56 | 黑底 + 红滚边 + X 发夹图标 |
| 弹幕样式 | 高度 40–48px | 深色气泡 `#18181E`，红滚边 |
| SC / 打赏动画 | 400×400 | 红色核心（取自武器核心）扩散 |
| 转场 | 1920×1080 | 黑红残影横向扫过，0.3–0.5 秒 |

**统一原则**：直播间整体是**深色系**，视觉焦点留给人物。

### B1.4 音声 / 语音包（如做）

- 语气：**平静、语速偏慢、句尾不上扬**
- 常用句：「……嗯。」「知道了。」「不用。」
- **禁止**：元气、撒娇、大声

---

## B2. 桌宠

| 项目 | 规格 |
|---|---|
| 基础尺寸 | 200×300 px（可按平台缩放） |
| 帧数 | 待机 4–8 帧 / 行走 6 帧 / 特殊动作 8 帧 |
| 素材来源 | 直接用 [Q 版精灵表](../design/illustration/lyco_chibi_sheet_9pose.png)（已有 9 姿势） |
| 必备动作 | 待机、走、拖拽、点击反应、睡眠 |
| 格式 | 透明底 PNG 序列 + 配置 JSON |
| 适配 | BongoCat / Shimeji / DesktopPet |

**点击反应设计**（符合人设）：
- 单击 → 侧目看一眼（**头不动，只转眼球**）
- 双击 → 微微歪头
- 拖拽 → 裙摆先动、身体后动（**滞后一拍**）
- 长时间无操作 → 闭眼（不是睡着，是懒得睁）

---

## B3. 实体周边

| 品类 | 规格 | 要点 |
|---|---|---|
| **亚克力立牌** | 100×150mm，3mm 厚 | 用全身立绘；**长杆必须完整入画** |
| **钥匙扣** | 50×50mm 内 | 只做**头部 + X 发夹**（缩小后仍可辨） |
| **徽章（吧唧）** | 58mm | 半身构图，深底 |
| **挂件（金属）** | 30×40mm | 直接做 **X 形发夹本体**（最聪明的周边） |
| **色纸** | 120×135mm | 战斗立绘 |

**周边通用**：深底 + 人物 + 红色点缀。**不要把背景做成白色**（黑衣服会糊）。

---

## B4. 数字商品

| 品类 | 尺寸 | 要求 |
|---|---|---|
| 头像 / 头像框 | 200×200 / 400×400 | 头部特写，**X 发夹必须可见** |
| 表情包 | 240×240 × 16 格 | 用「默认」档表情，配极简文案 |
| 输入法皮肤 | 按平台规范 | 深色底 + 红色候选栏高亮 |
| 动态壁纸 | 1920×1080 循环 | 裙摆缓动 + 极慢的红色呼吸 |
| 聊天气泡 | 九宫格 | `#18181E` 底 + `#B62833` 细边 |

---

## B5. 挂件自查清单

出任何挂件前过一遍：

- [ ] X 发夹在不在？形状对不对（**是 X 不是蝴蝶结**）？
- [ ] 红内层发 / 红内衬在不在？
- [ ] 色值全部来自配色指南？
- [ ] 表情是「默认」档（半垂眼、放松嘴）？
- [ ] 有没有不小心加了徽章 / 文字 / 边框？
- [ ] 如果是待机类：**够不够安静**？（她不该有多余小动作）
- [ ] 如果是缩小件（< 64px）：**X 发夹还能认出来吗**？

---

## B6. 优先级建议（先做哪个）

| 顺序 | 挂件 | 理由 |
|---|---|---|
| **1** | 待机动画 | 最能体现人设，且是直播的基础件 |
| **2** | 表情包 | 现有表情差分可直接用，成本最低 |
| **3** | 桌宠 | Q 版精灵表已有 9 姿势 |
| **4** | 头像 / 头像框 | 分发最广 |
| **5** | 直播间装饰套装 | 需要成套设计，工作量中等 |
| **6** | 实体周边 | 需要供应链 |
