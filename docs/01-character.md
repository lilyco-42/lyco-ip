# LYCO · 核心人设

> 本文件是角色的**唯一权威定义**。任何与本文冲突的下游产出都算错。

---

## 一、核心锚点

# 静态的秩序，动态的锋芒

她的身体被一条**分裂线**切开：**上半身完全静止，下半身一直在动。**

| | 上半身 | 下半身 |
|---|---|---|
| 动作 | **完全静止** | 一直在动 |
| 材质 | 挺括制服 | 柔软裙摆 |
| 语言 | 秩序 · 纪律 · 军官 | 速度 · 灵动 · 风 |
| 颜色 | 大面积黑 | 红藏在里面 |

**核心视觉反差**：纤细的身体 × 巨大的机械兵器；安静的上半身 × 流动的裙摆。

**为什么这条锚点重要**：它让这个角色**不依赖任何特定媒介**。
一张静态图能演（上半身静止 + 裙摆动），一段动画能演，一个 Live2D 皮套能演。
她是**为「待机 + 偶发动作」设计的角色**。

---

## 二、三条灵魂规则

### 1 · 高冷 = 安静，不是冷漠
靠「**没有明显情绪起伏**」演，不是靠压眉眼、绷嘴角、眯眼睛。
她不是不高兴，是**没什么值得反应的**。

| ✅ 正确 | ❌ 错误 |
|---|---|
| 半垂眼、放松的嘴 | 皱眉 / 瞪眼 |
| 面部肌肉全松 | 嘴角下压 / 咬牙 |
| 视线自然落点 | 凌厉眼神 / 杀气脸 |

### 2 · 极小的身体动作，极大的攻击效果
侧身闪避「**无意**」—— 她甚至没有完整地看向对手。
那不是挑衅，是**认为没必要做多余的动作**。

**输出原则**：动作幅度给在**兵器与裙摆**上，身体本体尽量小。

### 3 · 光从衣服里面透出来
红色**不是装饰，是运动的结果**。
静止时几乎没有红；一旦动起来，红从裙摆内衬、发下内层透出来。

| ✅ 正确 | ❌ 错误 |
|---|---|
| 运动时红色从内衬/发下透出 | 红当花纹贴在衣服表面 |
| 红光由内向外、有衰减 | 红描边、红发光特效常亮 |

---

## 三、性格与气质

- **不主动**：不解释、不辩解、不挑衅
- **不表演**：不为了显得酷而做动作
- **有礼貌但不热络**：会回应，但只回应必要的
- **内在是稳的**：不是压抑，是真的平静

**禁止的写法**：傲娇、毒舌、病娇、傻白甜、中二。
她要的是「**安静**」，不是任何一种强烈情绪的反面。

## 四、基础设定

| 项目 | 设定 |
|---|---|
| 名字 | Lyco（莉可） |
| 年龄感 | 17–19 |
| 体型 | **纤细**。肩窄、腰细、腿长但不过分；整体是「轻」的 |
| 头身比 | 约 1:6.5（偏动漫化，不写实） |
| 肤色 | 苍白偏暖 |
| 职业感 | 军官 / 技术者（不是战士，也不是法师） |

## 五、一段话给外人介绍她

> 一个穿黑色短款军装的少女，短黑发下藏着一层暗红。
> 她站着的时候像一张照片 —— 上半身一动不动，只有裙摆和发梢在走。
> 她动起来的时候，红色才从衣服里面透出来。
> 她不太看人，不是傲慢，是觉得没必要。

---

## 六、设计来源（为什么长这样）

三个关键词：**克制 · 纤细 · 流动**。

- **德式军装的秩序感** → 上半身的挺括、双排扣、腰带
- **不对称层叠裙的流动** → 下半身的速度感、红内衬的"运动结果"
- **近黑 + 深绯红 + 暖白 + 枪灰** → 冷的底子上一点热，且这点热是**被藏起来的**

**设计上的取舍**：放弃了常见的「大披风 + 华丽纹章 + 发光魔法」路线。
那些会让她变成「看起来很强的角色」，而她要的是「**看起来不想动，动起来很快**」。
