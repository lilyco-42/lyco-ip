## 三、用色禁忌

| ❌ 禁止 | 原因 |
|---|---|
| 高饱和纯红 `#FF0000` | 太跳，破坏「红是藏起来的」这个设定 |
| 金色 / 黄铜 | 会变成军装礼服感，偏离设定 |
| 大面积银 / 亮面 | 银只做小面积金属点缀 |
| 大面积红装饰 | 红只做内衬、滚边（1–2px）与运动残影 |
| 蓝、绿、紫等新色相 | 破坏配色识别度 |
| 纯黑 `#000000` 做大面积 | 会死板；用 `#121016`/`#18181E` 这类有色调的黑 |

## 四、红色的四条正确用法

红色是**唯一的热源**，用错就全崩。

| 用法 | 说明 |
|---|---|
| **1 · 发下内层** | 短黑发下藏一层深红，只在发尾与外翻时露出 |
| **2 · 裙摆内衬** | 不对称裙片翻开时，内侧的红 `#6E0D14`→`#B62833` 透出 |
| **3 · 细滚边** | 领口 / 袖口 / 前襟 1–2px 红边，克制 |
| **4 · 运动残影** | 高速移动时全身化成黑红残影，**只有脸保持清晰** |

**判定标准**：如果一张图里红色面积超过 25%，基本就是错的。
