## 一、头与脸

| 部位 | 规格 |
|---|---|
| 发型 | **短波波头（bob）**，长度到下颌线 |
| 发尾 | 略碎、外翘，**不对称**（不完全齐） |
| 刘海 | 厚重，**压住上半张脸**（约到眉线以下） |
| 分缝 | 偏分（右偏），不是中分 |
| 发色 | 外层近黑 `#121016`；**内层深红 `#8E1B24`** |
| 发夹 | **白色 X 形** `#F6F4F2`，**别在右侧刘海**（观众视角左侧） |

### 眼睛（最关键的识别点）

| 项目 | 规格 |
|---|---|
| 形状 | 大而**半垂** |
| 上眼睑 | **压住约 1/4 瞳孔**（这是"高冷"的唯一来源） |
| 瞳色 | 冷灰 `#8E8A96` |
| 高光 | 1 个小白点，**靠内**（不要两点闪亮） |
| 眉毛 | **极淡**，几乎看不见；不画挑眉 |
| 睫毛 | 上睫毛略重，下睫毛不画 |

### 嘴
- **放松、微闭**，一条很浅的线
- **绝不画笑**（嘴角不上扬）
- 不画嘴部特写的唇彩

## 二、身体比例

```
头身比 ≈ 1:6.5
肩宽 ≈ 1.4 个头宽        （窄肩）
腰宽 ≈ 0.9 个头宽        （细腰）
腿长 ≈ 3.4 个头高
```

**关键**：整体读作「**轻**」。不要画肌肉感、不要画丰满曲线。
她是「**纤细**」，不是「性感」。

## 三、服装分解

### 3.1 上身 · 短款双排扣军装

| 部件 | 规格 |
|---|---|
| 版型 | **短款**，下摆到腰线（不要长款风衣） |
| 领 | **高领**，立起，遮住脖颈一半 |
| 门襟 | **双排扣**，两列竖直银扣 `#C8CCD0`，每列 4–5 颗 |
| 滚边 | 领口 / 翻领 / 前襟 **红滚边 `#B62833`，1–2px** |
| 腰带 | **黑色细腰带** + 银方扣 + 一个小 **O 形环**（垂在扣下方） |
| 面料 | 挺括呢料感，大面积 `#18181E`，转折处 `#262630` |

### 3.2 下身 · 不对称层叠裙

| 部件 | 规格 |
|---|---|
| 廓形 | **不对称**：前短后长，两侧长片垂下 |
| 长度 | 前片到大腿中部，**不拖地** |
| 层次 | 2–3 层叠片 |
| 外层 | 黑 `#18181E` |
| **内衬** | **深红 `#6E0D14` → `#B62833`**，翻起时可见 |
| 动态 | 有**重量感** —— 动起来会**滞后一拍**（这是设计的灵魂） |

### 3.3 腿与脚

| 部件 | 规格 |
|---|---|
| 裤袜 | **深灰半透** `#46424E`（隐约透肤，**不是纯黑**） |
| 靴长 | **中筒**，到小腿中部 |
| 靴身 | 黑 `#121218`，靴面反光 `#22222A` |
| 靴底 | **红色** `#B62833`，厚底 |
| 扣带 | 红色扣带 1–2 道 |
| 跟 | **粗跟**（走得稳，不是细高跟） |

## 四、表情差分

基线是**同一个表情**，只做极微调。四个状态：

| # | 名称 | 变化 |
|---|---|---|
| 1 | **默认** | 半垂眼、嘴放松（**90% 时间用这个**） |
| 2 | **微讶** | 眼略睁 1–2px，**嘴形不变** |
| 3 | **闭眼** | 纯粹眨眼，无表情变化 |
| 4 | **侧目** | 眼球转向，**头不动**（她懒得转头） |

**禁止**：大笑、哭、怒、害羞脸红、星星眼。

## 五、动作规范

| 动作 | 身体 | 裙摆 / 头发 | 红色 |
|---|---|---|---|
| **待机** | 几乎不动，呼吸起伏极小 | 微风缓动，滞后 | 无 |
| **侧身闪避** | 侧过约 **30°**，幅度极小 | 裙片甩开 | 内衬一闪 |
| **反击充能** | 保持放松，手部微收 | 微微抬起 | **由内向外透出** |
| **红色闪光（突进）** | 全身化成黑红残影 | 拉成长条 | **大面积，但脸保持清晰** |

### 动作三原则
1. **上半身永远比下半身安静**
2. **幅度给在兵器与裙摆**，身体本体尽量小
3. **红色是结果不是原因** —— 先有动作，才有红

## 六、武器 · 机械长杆

| 形态 | 描述 |
|---|---|
| **收束** | 便携短杆，约前臂长，收在身侧 |
| **步枪** | 长杆展开 + 枪管，约身高的 1.2 倍 |
| **镰刀** | 巨大红黑弯刃，刃长超过身高 |

| 部件 | 规格 |
|---|---|
| 杆身 | 细长，哑光黑 `#121218` |
| 关节 | 银色 `#C8CCD0` |
| 核心 | 顶端**圆形红色机械核心** `#B62833`（唯一常亮元素） |
| 材质 | 哑光黑金属 + 银关节，**不反光成镜面** |

**对比核心**：纤细的身体 × 巨大的机械兵器。画的时候**兵器要大**，反差才有。

## 七、常见错误（自查清单）

- [ ] 眼睛画成锐利/上挑 → 应半垂
- [ ] 画了笑容 → 应放松微闭
- [ ] 红色成了大面积装饰 → 应只在内衬/滚边/残影
- [ ] 头发画成纯黑一片 → 应有 `#1E1B24`/`#2A2630` 发丝高光
- [ ] 黑衣服和黑头发糊在一起 → 应加边缘高光分开
- [ ] 兵器画小了 → 应夸张放大
- [ ] 裙子画成对称 → 应不对称层叠
- [ ] 画了徽章/勋章/肩章 → **禁止**
- [ ] 画面里出现文字 → **禁止**
- [ ] 加了画框/蓝图/网格 → **禁止**
