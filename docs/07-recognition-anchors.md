# LYCO · 识别锚点体系

> **本文件回答一个问题：别人凭什么一眼看出这是 Lyco 的二创？**
>
> 这是 IP 设计的核心。一个标记只有在**被搬走、被缩小、被别人重画**之后仍然成立，才算锚点。

---

## 一、锚点的四种损失

任何标记都要扛住这四种损失。只在一个条件下成立的，对 IP 无效。

| 损失 | 从 → 到 | 例子 |
|---|---|---|
| **分辨率损失** | 3000px 立绘 → 3px 像素 | Minecraft 皮肤 |
| **风格损失** | 二次元 → 写实 / 黏土 / 像素 | 3D 建模、手办 |
| **裁切损失** | 全身 → 只画头 / 只画背影 | 头像、角色卡 |
| **媒介损失** | 静态图 → 动画 / 游戏 | Live2D、游戏 mod |

---

## 二、五层锚点（每层至少一个）

**核心原则**：不管怎么损失，**总有一层活下来**。

| 层级 | 锚点 | 在什么情况下起作用 |
|---|---|---|
| **L1 剪影** | 不对称裙（长片**固定在她右侧**）+ 长杆 + 窄肩 | 远距离、单色、纯黑剪影 |
| **L2 色块** | **上黑下红** —— 红永远从**下/内**透出 | 缩小、模糊、看不清细节 |
| **L3 细节** | **白色 X 发夹**（右侧刘海、倾斜约 15°） | 特写、头像、大头 |
| **L4 动态** | **黑红锐利残影 + 脸保持清晰** | 动画、游戏、动作图 |
| **L5 行为** | **上半身静止、下半身流动** | 任何动态媒介 |

### 为什么必须是五层

| 场景 | 活下来的层 |
|---|---|
| 3px 像素图 | L1（剪影）+ L2（黑红分布） |
| 全身立绘 | L1 + L2 + L3 + L4 |
| 只画头 | L3（发夹）+ L2（黑发红内层） |
| 只画背影 | L1（裙）+ L2（红内层发） |
| 动画片段 | L4 + L5 |
| 写实手办 | L1 + L2 + L3 |

**若只有 L3（发夹）** → 头像之外全废。
**若只有 L4（特效）** → 静态图全废。
**所以必须五层齐全。**

---

## 三、逐层规格（可执行）

### L1 · 剪影锚点

**现状问题**：黑军装 + 短裙 + 长杆是**常见组合**，纯黑剪影认不出。

**硬规则（新增）**：

| 规则 | 内容 |
|---|---|
| **L1-1** | 不对称裙的长片**永远在她右侧**（观众视角**左侧**），不倒转 |
| **L1-2** | 前片永远短至**大腿中部**，后/侧片垂下至**膝盖下** |
| **L1-3** | 长杆**永远出现在剪影里**（除非明确画"无武器状态"） |
| **L1-4** | 肩宽严格 **1.4 头宽**，不要画宽 |

**判定**：把图填成纯黑，还能认出是 Lyco → L1 合格。

> ⚠️ 这条是当前最弱的一环。建议所有外发稿件**强制附加"纯黑剪影自检图"**。

---

### L2 · 色块锚点

**锚点内容**：**上黑下红** —— 红永远从**下方**或**内部**透出，绝不出现在上方或外部。

| 规则 | 内容 |
|---|---|
| **L2-1** | 画面垂直方向上，**黑在上、红在下** |
| **L2-2** | 红只从**裙内衬 / 发下层 / 靴底**三个位置出 |
| **L2-3** | 红总面积 **15–25%**（超过 25% 就错） |
| **L2-4** | 缩到 32px 宽时，应能看出"黑块下缘有一条红" |

**判定**：缩成 32px 宽，还能看出是 Lyco 的配色 → L2 合格。

---

### L3 · 细节锚点（白色 X 发夹）

| 规则 | 内容 |
|---|---|
| **L3-1** | 形状是 **X（交叉）**，不是蝴蝶结 / 星星 / 一字夹 |
| **L3-2** | 颜色 `#F6F4F2`，哑光，**不加反光/宝石/金属边** |
| **L3-3** | 位置**固定在她右侧刘海**（观众视角左侧） |
| **L3-4** | 尺寸约 **0.35 头宽**，倾斜约 **15°**，不正十字 |
| **L3-5** | 数量**恒为 1 个** |

#### ★ 低分辨率降级规则（新增，必须遵守）

| 可用像素 | 呈现方式 |
|---|---|
| **≥ 16px** | 完整 X（两笔等长交叉） |
| **8–15px** | X 退化为**白色十字点**（一个圆点 + 十字） |
| **3–7px** | 退化为黑发上**一个白色斜向短划**（约 45°） |
| **< 3px** | 放弃发夹，改用 **L2 红内层发**做识别 |

**为什么需要这条**：Minecraft 皮肤实测（8×8 的脸）证明，X 在 3px 下完全认不出。
**降级必须提前规定，不能让每个画师自己猜。**

---

### L4 · 动态锚点

**锚点内容**：**黑红锐利残影 + 脸保持清晰**。

| 规则 | 内容 |
|---|---|
| **L4-1** | 高速运动时全身化成**黑红残影**，**只有脸保持清晰** |
| **L4-2** | 残影形状是**锐利细长条（streak）**，**不是柔和光晕（glow）** |
| **L4-3** | 红光是**运动的结果** —— 先有动作，才有红 |
| **L4-4** | 静止时**几乎没有红** |
| **L4-5** | 唯一允许的常亮红：武器顶端的**圆形机械核心** |

> ⚠️ **L4-2 是最容易做签名的一条。** 烂大街的是"柔和红色光晕"；
> **有棱角的红** 是 Lyco 独有的。这条一立，别人一眼就能认出来。

---

### L5 · 行为锚点（最独特）

**锚点内容**：**上半身静止、下半身流动**。

| 规则 | 内容 |
|---|---|
| **L5-1** | 待机时上半身**几乎不动**，只有呼吸（≤2px）+ 头发裙摆缓动 |
| **L5-2** | 闪避幅度极小，**视线不追对手** |
| **L5-3** | 裙摆动作**滞后一拍**（有重量感） |
| **L5-4** | 幅度给在**兵器与裙摆**，身体本体尽量小 |

**这是 Lyco 唯一"别人抄不走"的东西** —— 因为它不是形状，是**行为**。
形状可以描，行为要理解。

---

## 四、锚点优先级（做减法时砍哪个）

当媒介受限、必须砍掉一些特征时，**按此顺序保留**：

```
1. L2 上黑下红          ← 最先保，成本最低
2. L3 白色 X 发夹        ← 头部可见就保
3. L1 不对称裙（右侧长片）← 全身可见就保
4. L4 黑红锐利残影       ← 有动作就保
5. L5 静止的上半身       ← 有动态就保
```

**判定**：一张图只要保住 **前 2 条**，就还能被认出是 Lyco。

---

## 五、常见失败案例

| 失败 | 缺了哪层 |
|---|---|
| 缩小后认不出 | **L2 太弱**（红分布不对） |
| 换个画师就不像 | **L3 规格没写死**（发夹位置/角度飘） |
| 头像很好但全身怪 | **L1 剪影缺失** |
| 动起来不像她 | **L5 行为没抓住**（动作太大） |
| 一眼看成别的红发角色 | **L4-2 红用了柔和光晕** |

## 六、给合作方的交付要求

外发稿件**必须**附以下自检图：

| 自检图 | 检验 |
|---|---|
| **纯黑剪影图** | L1 |
| **32px 缩略图** | L2 |
| **头部特写** | L3 |
| **动态关键帧（如有）** | L4 |

**没有这四张自检图的稿件不予验收。**
